# ⚛️ The Big Bang Theory — Fan Archive

> An unofficial fan tribute page featuring Chuck Lorre vanity cards, episode trivia, and fun facts for all 12 seasons of The Big Bang Theory.

---

## 🌌 About

This is a static fan-made web page built as a personal project. Pick any season and episode to reveal:

- 📜 **Chuck Lorre-style vanity card** — written in his signature philosophical, self-deprecating voice
- 🧪 **Episode trivia** — behind-the-scenes production notes and writer insights
- ⚡ **Fun facts** — real-world ripple effects and curiosities from each episode
- 🎨 **Fan art panel** — rotating public domain & CC-licensed science imagery

Seasons 1–3 have fully hand-crafted, episode-specific content. Seasons 4–12 use accurate episode titles with curated rotating content pools.

## 🎨 Design

- **Dark cosmic aesthetic** — starfield background with nebula colour washes
- **Typography** — Orbitron (display) + Space Mono (mono) + Rajdhani (body)
- **Colour palette** — deep space black with amber gold, electric blue, and violet accents
- **Fan art** — public domain and Creative Commons science imagery from NASA, ESO, and Wikimedia Commons
- **Animations** — spinning atom header, floating icons, staggered card fade-ins
- Fully **responsive** for mobile and desktop

---

## 🛠️ Tech Stack

Plain HTML, CSS, and vanilla JavaScript — no frameworks, no build step, no dependencies.

## 📦 Deployment

This site is deployed via **GitHub Pages** from the repository root.

To deploy your own copy:

1. Fork or clone this repository
2. Go to **Settings → Pages**
3. Set source to `main` branch, root folder
4. Save — your site will be live at `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`
